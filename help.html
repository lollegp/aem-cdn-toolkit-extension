Set up your first environment

  1. Open the extension popup, then Settings.
  2. Select Add environment and enter a unique name.
  3. Enter the HTTPS AEM publish origin, then add a public country URL and its publish path prefix.
  4. Enter your edge key. Add a purge key if you need CDN purge.
  5. Choose the publish opening mode and purge controls. Full purge is disabled for new environments.
  6. Select Save environment and grant access to the configured hosts.
  7. Visit a matching public page and open the popup. Select the environment and country if more than one matches.

You need access to an AEM as a Cloud Service publish environment and its CDN keys. This tool does not provision AEM or issue credentials.

Understand purge results

Succeeded means the server returned an explicit “ok” response. Accepted means the HTTP request succeeded without explicit completion confirmation. Unknown means the request outcome could not be confirmed; verify before retrying.

Full purge affects all cached resources and countries for the selected publish service. Enable it only for environments where you intend to use it.

Back up and troubleshoot

Import, export and reset are at the bottom of Settings. Exports omit keys by default; select “Include saved keys” only for a private backup. Reset clears environments and keys but retains activity, which has its own clear control.

If changes do not appear after a local update, reload the extension in Chrome's extension manager, then close and reopen Settings and the popup. The publish button shows whether the saved setting opens a tab or a window.

Report an issue or request help. Include the extension version and error text. Never include credentials, private URLs, or exported configurations containing keys.
