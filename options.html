AEM · CDN · ENVIRONMENTS

Environment settings

One publish origin and one pair of CDN keys per environment. Multiple public country sites.

Environment

The same publish origin is used by every country in this environment. Enter an HTTPS origin without a path.

Purge settings

Show the full purge action for this environment. It purges all cached resources across every country. PROD is disabled by default and can be enabled explicitly.

When disabled, page and full purge run immediately on click. When enabled, page purge requires confirmation and full purge also requires typing PURGE followed by the environment name.

Country mappings

Country codes must be unique, for example GB, IE or US. Public URL prefixes are supported. Leave the publish path prefix as / when both URLs use the same path.

AEM CDN credentials

Used for publish navigation and CDN purge.

Used only for CDN purge requests.

Keys belong to the environment and are shared by its countries. Set edgeKey and purgeKey directly in config.json or import a JSON configuration. Keys are saved with the environment and remain available after restart. Exports include keys.

X-Forwarded-Host is derived automatically from the public site's host, without protocol or path. Full environment purge uses X-AEM-Purge: all and follows this environment's purge settings.

Purge activity

The latest 100 requests are saved locally. This records the API response, not a separate CDN completion check. Keys and raw response bodies are never logged.

Import configuration

This replaces all environments, clears active publish headers and loads the environment keys from the imported file. Version 1 mappings are migrated when each environment has one publish origin. Generic purge API settings are replaced by the AEM CDN integration.
